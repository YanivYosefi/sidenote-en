# מכונת רילס

מייצרת סרטונים אנכיים (1080×1920) מהתוכן שכבר יש באתר, בחינם.

## הסוגים

| סוג | מה רואים | קהל |
|---|---|---|
| ביטוי (`expr`) | פתיח, הביטוי, משמעות, דוגמה עם הדגשה, מתי משתמשים | עברית → אנגלית |
| דמו (`demo`) | שאלה ל-Claude, תשובה מהירה, והביטוי שיוצא ממנה | עברית, אנגלית |
| חידון (`quiz`) | מה זה אומר? שלוש תשובות, ספירה 3-2-1, חשיפה | עברית, אנגלית |
| שלושה (`top3`) | שלושה ביטויים מאותו סוג ברצף | עברית → אנגלית |
| זה או זה (`vs`) | שתי מילים שמתבלבלים ביניהן, ומשפט עם שתיהן | עברית → אנגלית |
| מילולית / בפועל (`lit`) | התרגום המילולי נמחק, והמשמעות האמיתית מגיעה | אנגלית; גם ללומדי עברית |
| POV (`pov`) | שורות גדולות אחת-אחת בסגנון מם, ואז הביטוי | עברית, אנגלית; גם ללומדי עברית |

תוכן לקהל דובר אנגלית (ביטויים באיטלקית, ספרדית, צרפתית, וסלנג עברי) נמצא ב-`content-en.json`. זה סט דוגמה שכתבתי כדי לבדוק את הפורמטים. כדאי לעבור עליו לפני שמפרסמים.

**דוגמה אחת מכל סוג, לכל קהל (12 סרטונים):**
```
python reels/make.py --samples
```


לכל סרטון יוצאים שלושה קבצים: `reel.mp4`, `cover.jpg` (תמונת שער) ו-`caption.txt` (טקסט לפוסט עם האשטגים).

## להפיק מהטלפון, בלי מחשב

1. בגיטהאב: **Actions** ← **reels** ← **Run workflow**
2. לבחור מה להפיק: סוג אחד (`expr`, `demo`, `quiz`, `top3`, `vs`), הכל, או סרטון אחד לפי שם (למשל `ship-it` או `quiz-dogfooding`)
3. בערך 40 שניות לכל סרטון. בסוף, בתחתית הריצה, מורידים את **reels** כקובץ zip

זה רץ על המחשבים של גיטהאב, בחינם לריפו ציבורי.

## מוזיקה

הסרטונים יוצאים בלי מוזיקה, בכוונה. להוסיף סאונד טרנדי באפליקציה של אינסטגרם או טיקטוק זה חינמי ומביא יותר חשיפה מכל שיר שנבחר מראש. אם בכל זאת רוצים שיר קבוע (שיש לכם זכויות עליו):

```
python reels/make.py --music track.mp3
```

## להפיק על המחשב

```
pip install playwright && python -m playwright install chromium
python reels/make.py                # הכל
python reels/make.py --id ship-it   # סרטון אחד
python reels/make.py --only demo    # רק דמו
```

צריך גם ffmpeg מותקן.

## להוסיף תוכן

כל דף ביטוי חדש ב-`en/` הופך אוטומטית לסרטון. הטקסטים של הפתיח לפי סוג הביטוי נמצאים ב-`HOOKS`, בתוך `template.html`.

## תמונות שיתוף לדפי הביטויים

כשמשתפים דף ביטוי בוואטסאפ, פייסבוק או לינקדאין, מוצגת תמונה עם הביטוי והמשמעות שלו. אחרי שמוסיפים דף ביטוי חדש, מריצים:

```
python reels/og.py
```

זה מצייר את התמונה ל-`media/og/` ומחבר אותה לדף.
